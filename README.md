# 🚗 Japan Gas Station Finder

일본 현지 생활 중 주변 저렴한 주유소를 쉽게 찾을 수 없다는 불편함에서 출발한 프로젝트입니다.
iOS/Android 동시 지원을 목표로 React Native로 개발했습니다.

## 📱 주요 기능

- 현재 위치 기반 주변 주유소 표시 (Google Maps API 연동)
- 연료 종류 필터링 (레귤러 / 하이옥탄 / 디젤)
- 가격순 정렬
- 즐겨찾기 저장
- 길찾기 연동 (Google Maps)
- 다크모드 대응
- 주유소 이름 검색 및 최근 검색어 저장

## 🛠 사용 기술

- React Native (TypeScript)
- Google Maps API
- Geolocation
- AsyncStorage

## ⚠️ 현재 상태

기능 구현 완료 후 실제 일본 주유소 API를 연동할 계획이었으나,
UI 인터랙션 수정 과정에서 코드 충돌이 발생해 미완성 상태입니다.
현재는 더미 데이터로 동작합니다.

## 📚 배운 점

- 처음으로 크로스플랫폼 앱 개발에 도전하며 React Native 독학
- Google Maps API 연동 및 실시간 위치 추적 구현 경험
- 실제 사용자 불편함에서 출발한 서비스 기획 경험
